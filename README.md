# Quiz Game Project

## 프로젝트 개요
세계 여러 나라의 수도를 주제로 만든 Python 콘솔 퀴즈 게임입니다. 메뉴에서 번호를 선택해 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록 확인, 최고 점수 확인, 종료 기능을 사용할 수 있습니다.

## 퀴즈 주제 선정 이유
수도 맞추기 퀴즈는 문제를 만들기 쉽고 정답이 비교적 명확해서, 초보자가 조건문, 반복문, 클래스, 파일 저장 기능을 연습하기에 적합하다고 판단했습니다.

## 실행 방법
프로젝트 루트에서 아래 명령어를 실행합니다.

```bash
python3 main.py
```

## 기능 목록
- 메뉴 출력 및 번호 선택
- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 보기
- 최고 점수 확인
- `state.json` 파일 저장 및 불러오기
- 잘못된 입력, `KeyboardInterrupt`, `EOFError` 처리
- 파일이 없거나 손상된 경우 기본 데이터로 복구

## 파일 구조
```text
E1-2/
├── .gitignore
├── README.md
├── main.py
├── quiz.py
└── state.json
```

## 데이터 파일 설명
프로젝트 루트의 `state.json` 파일에 퀴즈 목록과 최고 점수를 UTF-8 인코딩으로 저장합니다.

- 경로: `./state.json`
- 역할: 프로그램 상태 저장
- 주요 스키마:

```json
{
  "quizzes": [
    {
      "question": "문제",
      "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
      "answer": 1
    }
  ],
  "best_score": 3
}
```
